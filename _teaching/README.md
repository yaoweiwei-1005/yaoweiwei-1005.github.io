# 授课 / 助教（Teaching）

导航栏 Teaching 页面（_pages/teaching.html）会自动列出本文件夹下的所有条目。

## 添加一条

新建文件 `YYYY-MM-DD-简短标题.md`，套用下面的模板：

```yaml
---
title: "课程名称"
collection: teaching
type: "Teaching Assistant"   # 或 "Lecturer" 等
permalink: /teaching/YYYY-MM-DD-简短标题
venue: "Shandong University"
date: YYYY-MM-DD
location: "Qingdao, China"
---
这里写课程简介、职责等，没有就留空
```
