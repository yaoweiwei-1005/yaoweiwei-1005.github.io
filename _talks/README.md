# 学术报告（Talks）

导航栏 Talks 页面（_pages/talks.html）会自动列出本文件夹下的所有条目。

## 添加一次报告

新建文件 `YYYY-MM-DD-简短标题.md`（日期填报告时间），套用下面的模板：

```yaml
---
title: "报告标题"
collection: talks
type: "Talk"             # 或 "Poster"
permalink: /talks/YYYY-MM-DD-简短标题
venue: "会议名称或邀请单位"
date: YYYY-MM-DD
location: "Qingdao, China"
---
这里写报告简介，slides 链接可以直接写在正文里
```
